Fond noir · boutons orange · texte blanc / gris mat · style terminal animé.

| Dossier | Contenu |

## Installer le lanceur
L'APK est compilé automatiquement par GitHub (onglet **Actions**).
Téléchargement direct : **Releases → `lanceur-lexos-pro` → `LexOS-PRO-Lanceur.apk`**.

1. Installe l'APK (autorise « Installer des applis inconnues »).
2. Bouton **Accueil** → **LexOS PRO** → **Toujours**.

Couleurs : `#000000` noir · `#0D0D0D` / `#121212` gris mat · `#2A2A2A` ligne · `#EDEDED` / `#9A9A9A` texte · `#E8590C` orange LexOS · `#C84B0A` orange bouton.

## Appareils
- **Galaxy A55** (Android 14+) : 8 applis épinglées.
- **Galaxy S25 Ultra** (Android 15, One UI 7) : même APK, 12 applis épinglées grâce au grand écran.
- Tout Android 8.0 et plus fonctionne.
