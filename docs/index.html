Questions

C'est quoi un APK?

C'est le fichier d'installation d'une appli Android. LexOS PRO s'installe directement, sans passer par le Play Store.

Est-ce que mon téléphone reste sécurisé?

Oui. L'écran de verrouillage LexOS s'affiche par-dessus, mais le déverrouillage reste celui de ton téléphone : ton empreinte ou ton NIP.

Pourquoi l'appli demande des autorisations?

Chaque fonction en option demande la sienne : l'accès aux notifications pour les noms animés et le verrouillage, l'affichage par-dessus pour les bannières, l'agenda pour tes événements, le téléphone pour le composeur. Tu actives seulement ce que tu veux.

Et les mises à jour?

Les nouvelles versions s'installent par-dessus l'ancienne, avec le même lien.

Je peux revenir à mon écran d'origine?

Oui : Paramètres → Applications → Choisir les applis par défaut → Appli d'accueil, puis ton lanceur d'origine.
